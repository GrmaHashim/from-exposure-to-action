# Data acquisition scripts

One `fetch_<source>.py` per dataset in the Data Dictionary's **Dataset Registry** tab. Each script downloads the source's raw file(s) into `data/raw/` and does nothing else — cleaning and joining happens in `src/analysis/`.

| Script | Dataset | Status |
|---|---|---|
| `fetch_aioe.py` | AIOE (Felten, Raj & Seamans) | ✅ implemented |
| `fetch_onet.py` | O\*NET core files (Tasks, Skills, Abilities, Job Zones) | ✅ implemented (FILES_OF_INTEREST corrected for v31.0's renamed files) |
| `fetch_ilo_genai.py` | ILO Generative AI and Jobs (2025 update, Working Paper 140) | ✅ implemented. `Final_Scores_ISCO08_...xlsx` is what's actually used (it carries pre-computed `mean_score_2025`/`SD_2025` per occupation); `4digits_with_tasks.xlsx` is downloaded but currently unused -- it turned out to hold categorical exposure labels, not a numeric score |
| `fetch_bls_crosswalks.py` | BLS ISCO-08<->SOC2010 and SOC2010->SOC2018 reference crosswalks | ✅ implemented, needed to join ILO/OECD's ISCO-08 codes onto the SOC-keyed master table -- but bls.gov blocks scripted downloads (403, WAF-level), so both files must be downloaded manually from [bls.gov/soc/2018/crosswalks.htm](https://www.bls.gov/soc/2018/crosswalks.htm) and saved as `data/raw/ISCO_SOC_2010_Crosswalk.xls` and `data/raw/SOC_2010_to_2018_Crosswalk.xlsx` |
| `fetch_oecd_exposure.py` | OECD AI Exposure Measure (AI Papers No. 59) | ⬜ blocked (report PDF downloads fine; O*NET-SOC-keyed, but OECD has not actually published the promised occupation-level xlsx/csv dataset -- checked oecd.ai, oecd.org, oecd-ilibrary.org, Data Explorer, GitHub; none exist yet) |
| `fetch_bls_oews.py` | BLS OEWS employment & wages (multi-year) | ✅ implemented and integrated (`employment_growth_rate`, annualized CAGR of total employment). Manual download required -- bls.gov WAF blocks the script's automated fetch; download 3 years of "All Data" National tables from [bls.gov/oes/tables.htm](https://www.bls.gov/oes/tables.htm) and save as `data/raw/oesm25nat.zip`, `oesm24nat.zip`, `oesm23nat.zip` -- `load_bls_oews_growth()` picks them up automatically once >=2 years are present; verified: `national_M<year>_dl.xlsx`, ~1400 rows/year keyed by OCC_CODE (SOC), TOT_EMP/H_MEAN/A_MEAN/A_MEDIAN wage columns, suppressed values marked "#" |
| `fetch_gpts_are_gpts.py` | GPTs are GPTs (Eloundou et al.) | ✅ implemented and integrated into `build_master_dataset.py`. occ_level.csv from the authors' own openai/GPTs-are-GPTs repo, keyed by O*NET-SOC Code, 923 occupations. `gpts_are_gpts_score` = `dv_rating_beta`, kept consistent with AIOE/ILO as an automated/model-based measure. Confirmed against the paper's own text that beta is the headline measure (80%/19% worker stats), but specifically `human_rating_beta` -- kept alongside as `gpts_are_gpts_human_score` for correct citation + cross-check (see `load_gpts_are_gpts_scores()`'s docstring) |
| `fetch_anthropic_economic_index.py` | Anthropic Economic Index | 🟡 partially integrated. The 1P API release (release_2026_06_26, dated 2026-06-26) is implemented and integrated (`anthropic_1p_automation_share`/`anthropic_1p_augmentation_share`, filtered to `category_name=="soc_occupation"`, keyed by `node_external_id`; kept OUT of `composite_exposure_score` -- real usage evidence, not a theoretical exposure score, feeds RQ2's cross-check instead). The richer claude.ai release is downloaded but NOT yet integrated -- it carries per-country breakdowns and multiple occupation hierarchy levels, and the exact global-aggregate row hasn't been confirmed yet. Output filenames carry the release date; the loader globs for the latest match rather than a hard-coded name |
| `fetch_statcan_canada.py` | Statistics Canada AI occupational exposure (appendix) | ✅ implemented. Saves the source article's HTML page (no separate CSV/XLSX exists -- page has both a simple 28-NOC-group x 3% Chart-1 table AND a richer Appendix Table A.2, May 2021, from Mehdi & Morissette 2024, Sept 3 2024). `load_statcan_noc_exposure()` in `build_master_dataset.py` parses Table A.2 (Employment, AIOE, Potential complementarity, Complementarity-adjusted AIOE, plus 3 exposure-percentage columns) -- deliberately NOT called from `merge_all()` / not joined onto the SOC-keyed master table, NOC-keyed, feeds one standalone appendix comparison chart only, per this project's guardrails |

Run each script from an environment with internet access to the source's own domain (your machine, Colab, or the Kaggle notebook itself with internet enabled) — this project's cloud dev sandbox has restricted network egress and cannot execute these downloads directly.
